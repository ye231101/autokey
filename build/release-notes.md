AutoKey types your text into any window the way a person would: uneven rhythm, natural pauses, and typos that get noticed and fixed.

## Which file do I need?

| Computer | Download |
| --- | --- |
| Windows 10 or 11 | `AutoKey-{version}-win-x64.exe` |
| Mac with Apple Silicon (M1 or later) | `AutoKey-{version}-osx-arm64.dmg` |
| Mac with an Intel processor | `AutoKey-{version}-osx-x64.dmg` |
| Linux on a standard PC | `AutoKey-{version}-linux-x64.tar.gz` |
| Linux on ARM64 | `AutoKey-{version}-linux-arm64.tar.gz` |

Not sure which Mac you have? Apple menu › **About This Mac**: "Chip: Apple M…" means Apple Silicon. The `osx-*.tar.gz` files contain the same Mac app as the disk images.

## First start

- **Windows:** run the .exe. If SmartScreen warns about an unknown publisher, choose **More info › Run anyway**.
- **macOS:** open the .dmg and drag **AutoKey** onto **Applications**. The app isn't notarized by Apple, so the first time go to **System Settings › Privacy & Security** and click **Open Anyway**. Then turn on AutoKey under **Privacy & Security › Accessibility** and reopen it.
- **Linux:** `tar xzf AutoKey-{version}-linux-x64.tar.gz && ./AutoKey/install.sh`, then start AutoKey from the applications menu. On Wayland, see the README to let AutoKey type into every app.

Hotkeys: **F8** (Windows, Linux) or **⌃⌥P** (macOS) starts, pauses and resumes; **Esc** stops.
